## Overview

A CDN caches content on servers close to users. It cuts latency for static and cacheable content and takes load off the origin servers.

## Outline

- How a CDN works: edge locations, origin and request routing
- Routing users to the nearest edge (DNS and anycast)
- Pull vs push CDNs
- Cache keys, Cache-Control headers and invalidation
- Origin shielding and tiered caching
- Edge computing
