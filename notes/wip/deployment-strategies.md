## Overview

Most outages follow a change. Deployment strategies limit how many users a bad release can hurt, and how fast we can undo it.

## Outline

- Blue/green deployments
- Canary releases and automated canary analysis
- Feature flags and dark launches
- Rollbacks and backward-compatible changes
- Configuration management and config as code
