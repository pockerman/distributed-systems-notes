## Overview

In a distributed system a single request touches many machines. Observability is our ability to see what the system is doing and why, from the data it emits.

## Outline

- Monitoring vs observability
- Structured logs
- Metrics: counters, gauges, histograms, and cardinality
- Distributed tracing: spans, context propagation, sampling
- OpenTelemetry
- The RED and USE methods
